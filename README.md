# BOTBOX Alpha v0.1

BOTBOX Family Edition is a private, AI-assisted family heritage and history home.

## Core idea

Create Family → Add Person → Upload/Drop → AI Analyze → Connect Person → Life Card → Ask BOTBOX

BOTBOX is designed to help families:

- preserve photos, documents, stories, audio, and video
- connect people, places, dates, and relationships
- identify missing information
- capture family memories
- build Life Cards and timelines
- ask questions across the family archive
- create future reunion, research, and family-business tools

## Included in this Alpha

- Family Home
- Big Drop screen
- People / Life Cards
- Ask BOTBOX demo
- Family Inbox
- Simple Timeline
- Prisma/PostgreSQL family data schema
- Mobile-first BOTBOX visual shell

## Not wired yet

## Next milestone

Build one real working path:

1. Create a family
2. Add a person
3. Upload one photo
4. Analyze the photo
5. Save provisional AI findings
6. Confirm a person
7. Link the photo to that person
8. Retrieve the confirmed family information through Ask BOTBOX

## Core BOTBOX rule

AI findings are suggestions, not family facts, until confirmed or supported by evidence.

## Brand promise

Preserve it. Connect it. Complete it. Pass it down.
